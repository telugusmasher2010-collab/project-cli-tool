- **CLI:** Go with `cobra`
- **Template Engine:** Go `text/template` + `embed`
- **Config:** Go `viper`
- **Cross-Compile:** `goreleaser`
- **CI/CD:** GitHub Actions
- **Distribution:** Homebrew, Scoop, AUR, npm
