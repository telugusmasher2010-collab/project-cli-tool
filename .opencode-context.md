## Tech Stack
- **CLI:** Go with `cobra`
- **Template Engine:** Go `text/template` + `embed`
- **Config:** Go `viper`
- **Cross-Compile:** `goreleaser`
- **CI/CD:** GitHub Actions
- **Distribution:** Homebrew, Scoop, AUR, npm

## Sector Contract
```
Sector ① (CLI Engine)
    │  Parses flags, collects variables
    │  Calls Sector ② with template name + variables
    ▼
Sector ② (Generator) ← YOU ARE HERE
    │  Reads embedded templates
    │  Substitutes variables
    │  Writes output to target directory
    │  Returns path or error to Sector ①
    ▼
Sector ① displays result to user
```

## File Sync (Git + GitHub — Syncthing retired)
- **GitHub repo:** https://github.com/telugusmasher2010-collab/project-cli-tool

- Manual fallback: `git add -A && git commit -m "msg" && git pull --rebase --autostash && git push`
